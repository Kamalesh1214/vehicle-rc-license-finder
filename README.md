## 🚗 Vehicle RC License Finder
A simple front-end web application that simulates retrieving vehicle registration (RC) details using a vehicle number.

🔗 Live Demo:  
https://kamalesh1214.github.io/vehicle-rc-license-finder

## 📌 Overview

The **Vehicle RC License Finder** is designed to provide a user-friendly interface for accessing vehicle-related information.  
It demonstrates how real-world vehicle verification systems work in a simplified manner.

## 💡 Features
- 🔍 Enter vehicle number to search details  
- 📄 Displays structured vehicle information  
- 🎯 Clean and intuitive user interface  
- ⚡ Fast and responsive design  

## 🛠️ Tech Stack
- HTML  
- CSS  
- JavaScript  

## ⚙️ How It Works
- The application takes a vehicle number as input  
- Matches it with predefined (static) data  
- Displays corresponding vehicle details on the screen  

> Note: This project currently uses static/local data and does not connect to any real-time API.
